# Automatic Backup System (Bash Script)

This project is a simple and reliable **automatic backup system** written in Bash.  
It creates a timestamped `.tar.gz` archive of any folder you choose and stores it in a backup directory, along with a log file that records each backup activity.

This script is designed to work on **Windows (Git Bash)**
---

## Features

✅ Automatically creates compressed `.tar.gz` backups  
✅ Saves backups into a specified folder  
✅ Generates a log entry for every backup  
✅ Auto-creates the backup directory if it doesn't exist  
✅ Cross-platform (Windows Git Bash / Linux / macOS)  
✅ Clean and simple Bash code
